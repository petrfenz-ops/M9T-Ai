# Obrázky (dílna)

Použitelné **workshop fotografie** — součásti, umístění, poškození, montáž.

## Pojmenování

```
m9t_<sekce>_<díl>_<pohled>[_verze].{jpg|png|webp}
```

Příklady:

- `m9t_snimace_map_sensor_umisteni.jpg`
- `m9t_turbo_wastegate_detail_01.png`
- `m9t_postupy_vstrik_demontaz.webp`

## Požadavky

- Ostrost vhodná pro dílnu (dostatečné DPI / rozlišení)
- Bez watermarků a těžkých kompresních artefaktů
- V PR: zdroj + odkaz na sekci/kartu atlasu
- Před merge: položka v `verification/CHECKLIST.md`
